# Pocket Smart AI

## 📌 About the Project

**Pocket Smart AI** is an AI-powered personal finance web application designed to help users manage their budgets, understand spending habits, and receive intelligent recommendations.

The project combines a **FastAPI backend**, **SQLite database**, and **Gemini AI integration** with a simple web interface.

## 🎯 Objectives

- Help users manage personal budgets and expenses.
- Provide AI-assisted financial recommendations.
- Store application data using SQLite.
- Build a modular backend using FastAPI.
- Provide a simple and user-friendly web interface.

## ✨ Features

- AI-powered recommendations
- Budget and expense assistance
- FastAPI-based backend

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd "Pocket Smart AI"
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the FastAPI server

```bash
python -m uvicorn main:app --reload
```

### 5. Open the application

Open the local URL shown by Uvicorn in your browser.
